`# 📚 Bookstore API Test Automation


This repository contains a **modular API testing framework** built with:
- **Java 17**
- **Spring Test Context** (for property and DI management)
- **Rest-Assured** (for HTTP client abstraction)
- **TestNG** (for parallel and suite execution)
- **Allure Reporting** (for detailed visual reports)
- **GitHub Actions CI/CD**


### Run Locally
```bash
mvn clean test
allure serve - for report generation
